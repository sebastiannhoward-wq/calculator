CALCULATOR REQUIREMENTS

1. can add 2 numbers (if add is selected and the first input is 1 and the second input is 2, the program should output 3)
2. can subtract one number from another (if subtract is selected, 1 as the first input and 2 as the second input, the output should be -1)
3. can multiply one number by another (if multiply is selected,4 as the first input and 2 as the second, the output should be 8)
4. can divide one number by another (if divide is selected, 4 as the first input and 2 as the second, the output should be 2)
5. these results can be displayed to the user
6. the calculator should be able to perform each operation in under a second
